# 3D Printed Smart Desk Lamp

A simple and functional 3D-printed desk lamp designed to be used with a smart LED light bulb.

The lamp was designed to provide ambient lighting while maintaining a simple and minimal appearance. The main structural components are 3D printed, while the electrical components are commercially available.

The STL files are included in this repository so anyone can download and print their own version.

## Print Settings

The lamp was printed on an **Ender 3 Neo** using PLA.

- **Printer:** Ender 3 Neo
- **Material:** PLA
- **Layer height:** 0.2 mm
- **Print speed:** 45%
- **Infill:** 100%
- **Supports:** None

The print speed was reduced to 45% to achieve better surface detail and print quality.

The lamp shade is designed as a hollow part, so it does not contain internal infill despite the 100% infill setting. The infill setting applies to the solid sections of the printed parts.

## BOM — Bill of Materials

The following components are required in addition to the 3D-printed parts:

| Component | Quantity | Description |
|---|---:|---|
| LEDVANCE SMART+ smart bulb | 1 | Smart LED light bulb |
| Smooth lamp socket | 1 | Socket for the light bulb |
| High-voltage electrical cable | 40 cm | 2 mm diameter |
| KCD1-101 rocker switch | 1 | 6A, 2-pin, black, 20 mm, ON/OFF |

All of the main structural parts of the lamp are 3D printed.

## Assembly Instructions

### 1. Print the parts

Download the STL files from the `STL` folder and print them using the recommended settings.

### 2. Assemble the lamp body

After printing, remove any imperfections and clean the parts if necessary.

The cylindrical lampshade fits onto the printed base.

### 3. Install the lamp socket

Place the smooth lamp socket inside the printed base and make sure it is securely positioned.

### 4. Install the electrical components

Connect the high-voltage cable to the lamp socket and route the cable through the base.

The KCD1-101 rocker switch is used as the ON/OFF switch for the lamp.

### 5. Install the smart bulb

Install the LEDVANCE SMART+ smart bulb into the lamp socket.

The smart bulb can then be controlled through its compatible smart-home system.

### Safety

**⚠️ Warning:** This project involves mains voltage. Electrical connections must be properly insulated and enclosed. Never work on the electrical components while the lamp is connected to the power supply.

If you are not familiar with mains electrical wiring, ask a qualified person for help.
